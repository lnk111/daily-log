# Handoff: 데일리 로그 (Daily Log) — 기록·KPT 회고·가계부

## Overview
"데일리 로그"는 하루의 활동(아침·회사·저녁), KPT 회고(Keep / Problem / Try), 그리고 가계부(생활비·수입·지출·투자 자금 관리·적금)를 한 앱에서 기록·회고하는 개인용 서비스입니다. 핵심 차별점은 **투자 자금 관리** — "이번 달 계좌별로 배정한 돈을 실제로 얼마나 집행(매수)했는가"를 배정 / 매수 / 대기(=max(0, 배정−매수)) / 손익으로 추적합니다. 토스 스타일의 단일 웹앱(PWA), 구글 로그인 1회로 모든 기기 동기화를 전제로 합니다.

이 번들은 그 제품의 **와이어프레임**과 사용자 플로우를 담고 있습니다.

## About the Design Files
이 번들의 파일들은 **HTML로 만든 디자인 레퍼런스**입니다 — 의도한 구조·레이아웃·플로우를 보여주는 프로토타입이며, 그대로 복사해 프로덕션에 넣는 코드가 아닙니다. 목표는 이 HTML 디자인을 **대상 코드베이스의 기존 환경(React/Vue/SwiftUI/네이티브 등)에서 그 코드베이스의 확립된 패턴·라이브러리로 다시 구현**하는 것입니다. 아직 환경이 없다면 프로젝트에 가장 적합한 프레임워크를 선택해 구현하세요.

이 프로젝트에는 **shadcn/ui 디자인 시스템**이 연결되어 있습니다. 스타일링은 이 와이어프레임의 색·간격을 픽셀 단위로 베끼지 말고, **shadcn/ui의 컴포넌트와 토큰(Card, Button, Tabs, Sheet, Progress, Badge, Calendar 등)으로 입히세요.**

## Fidelity
**로우파이(lofi) 와이어프레임입니다.** 손그림 톤의 무채색 목업으로 레이아웃·정보구조·플로우·상태를 정의합니다. 색/타이포/그림자 같은 시각 디테일은 최종안이 아니므로, 레이아웃과 기능의 가이드로만 쓰고 **실제 스타일은 코드베이스의 디자인 시스템(shadcn/ui)을 적용**하세요. 단, 아래 "의미를 가진 색"은 정보 전달 목적이므로 유지해야 합니다.

## Information Architecture (3-탭)
하단 탭 3개로 구성된 단일 웹앱입니다.
- **📝 기록 탭** — 날짜 이동(오늘/이전·다음). 내부는 서브 세그먼트 컨트롤 **[일지 · 회고 · 가계부]** 로 전환.
  - 일지: 아침 🌅 / 회사 🏢 / 저녁 🌙 각 구역에 자유 텍스트 라인.
  - 회고: KPT (Keep / Problem / Try) 각 한 줄. 저녁에 하루 1회 작성.
  - 가계부: 생활비 히어로 숫자 + 투자 요약 + 오늘 내역 리스트 + [＋ 기록하기].
- **🗓 달력 탭** — 월 달력, 기록이 있는 날에 점(●) 표시, 상단에 "이 달에 N일 기록". 날짜 탭 → 그 날 기록으로 이동.
- **🔁 회고 탭** — 주간/월간 토글 + 기간 이동. 수입·지출·투자 매수·적금 합계 카드 + KPT 모아보기.

## Desktop (PC) Layout
모바일과 같은 정보·팔레트를 쓰되, 넓은 폭에서는 레이아웃을 재배치합니다 (와이어프레임 08·09).
- **하단 탭바 → 좌측 사이드바 내비**: 기록 / 달력 / 회고 + 하단 프로필. 활성 항목은 포인트 컬러 tint(`#ecebfb` 배경 / `#4a45c7` 텍스트).
- **기록 화면**: 세그먼트 전환 대신 **일지 · 회고(KPT)를 2컬럼**으로 동시 노출하고, **가계부·투자 관리는 우측 레일(약 280px)** 에 상시 표시 → 하루 전체를 스크롤 없이 한눈에.
- **회고 화면**: 주간/월간 토글 + **KPI 카드 4개 + 요일별 지출 차트 + KPT 모아보기**의 대시보드 레이아웃. 차트 강조는 포인트 컬러.
- **브레이크포인트 가이드**: 모바일(단일 컬럼 + 하단 탭바) → 태블릿/좁은 데스크톱(사이드바 + 단일 메인) → 넓은 데스크톱(사이드바 + 다중 컬럼 + 우측 레일). shadcn 레이아웃 프리미티브 + Tailwind 반응형 유틸로 구현 권장.

## Screens / Views

### 1. 로그인 (온보딩 · 빈 화면)
- **Purpose**: 최초 진입, 구글 계정으로 로그인.
- **Layout**: 세로 중앙 정렬. 상단 앱 로고/이름, 중앙 로그인 카드, 하단 보조 카피.
- **Components**:
  - 앱 타이틀 "데일리 로그", 서브타이틀 "하루 기록 · 회고 · 가계부".
  - 로그인 카드: 안내문 + **[G 구글로 로그인]** 버튼(주요 CTA).
  - 보조 카피: "로그인 한 번으로 모든 기기에서 끊김 없이 동기화".
- **Behavior**: 로그인 성공 → 데이터 있으면 복원, 신규면 투자 계좌 가이드로. 완료 후 기록 탭 진입.

### 2. 기록 탭 — 서브 세그먼트 (핵심 화면, 3 상태)
상단에 세그먼트 컨트롤 [일지 / 회고 / 가계부]. 활성 세그먼트만 채워짐. 아래 3개 뷰는 같은 탭의 세그먼트 전환 상태입니다.

**2a. 일지**
- 헤더: "데일리 로그" + "✓ 저장됨"(자동저장 표시) + 사용자 아바타.
- 날짜 내비게이터: ◀ 6월 25일 (수) ▶.
- 세그먼트: [일지(활성) / 회고 / 가계부].
- 본문: 🌅 아침 / 🏢 회사 / 🌙 저녁 각 섹션, 항목은 밑줄 라인 형태의 텍스트 입력.

**2b. 회고**
- 세그먼트: [일지 / 회고(활성) / 가계부].
- KPT 카드 3개(각각 라벨 + 한 줄 입력):
  - KEEP · 계속 이어갈 것 — **초록(#2f9e69)** 라벨/좌측 바.
  - PROBLEM · 아쉽거나 막혔던 것 — **빨강(#d9694f)**.
  - TRY · 다음에 시도해볼 것 — **파랑(#3f7cc0)**.
- 보조 카피: "한 줄이면 충분해요 · 저녁에 하루 1회".

**2c. 가계부**
- 세그먼트: [일지 / 회고 / 가계부(활성)].
- 히어로: 라벨 "오늘 쓸 수 있는 생활비" + 큰 숫자(예 1,240,000) + 보조(투자 매수 / 배정 / 적금).
- 투자 요약 줄: "📈 투자 — 매수 500만 · 대기 240만 ▸" (탭 시 투자 관리로).
- 오늘 내역 리스트(각 행: 색점 + 라벨 + 금액):
  - 수입 · 환급 — **초록**, +50,000
  - 지출 · 점심 — 무채(회색 점), -12,000
  - 매수 · S&P500 [키움] — **빨강**, -300,000
  - 매도 · 애플 [한투ISA] — **파랑**, +120,000
  - (적금은 무채)
- 주요 CTA: **[＋ 기록하기]** (포인트 컬러).

### 3. 입력 바텀시트
- **Purpose**: 내역 한 건 추가. 화면을 어둡게(dim) 깔고 하단에서 시트가 올라옴 → shadcn **Sheet**(side="bottom") 또는 Drawer.
- **Components**:
  - 유형 선택: 지출 / 수입 / 매수 / 매도 / 적금 (버튼 그리드, 선택 시 채워짐).
  - **계좌 드롭다운은 유형이 매수·매도일 때만 노출** (조건부).
  - 종목/내용 입력, 금액 입력(큰 숫자).
  - [추가] 버튼(주요 CTA).
- **Behavior**: 추가 시 오늘 내역·생활비·투자 요약이 자동 갱신.

### 4. 투자 관리 (계좌별)
- **Purpose**: 계좌별 배정/매수/대기 및 손익 확인.
- **Components**:
  - 계좌 카드(반복): 계좌명 + [배정 / 매수 / 대기] 수치 + **진행바(매수/배정 비율)** → shadcn **Progress**.
    - 예: 키움증권 배정 440만 · 매수 300만(빨강) · 대기 140만, 진행 68%.
  - 합계 카드: 투자수익(손익, +면 초록) / 투자 대기금 총액.
  - [＋ 계좌] / [계좌 삭제].
  - 안내: "매월 1일 배정·대기·손익 자동 초기화".

### 5. 투자 빈 상태 가이드
- 계좌 없을 때 3단계 온보딩: 1) 계좌 추가 → 2) 이번 달 배정 금액 입력 → 3) ＋기록하기 → 매수.
- [＋ 계좌 추가] CTA.

### 6. 달력 탭- 월 헤더(◀ 2026년 6월 ▶), "이 달에 18일 기록했어요" 요약 배지.
- 요일 헤더 + 날짜 그리드. 기록 있는 날에 점(●). 오늘/선택일은 포인트 컬러로 강조 → shadcn **Calendar** 커스터마이즈 또는 커스텀 그리드.
- 날짜 탭 → 해당 날짜의 기록 탭으로 이동.

### 7. 회고 탭
- 주간/월간 세그먼트 토글 + 기간 이동(◀ 6/19–25 ▶).
- 합계 카드 4개: 수입(초록) / 지출 / 투자 매수(빨강) / 적금.
- KPT 모아보기: Keep(초록)/Problem(빨강)/Try(파랑) 각 카드에 날짜별 항목 나열.

## Interactions & Behavior
- **자동 저장**: 기록 입력은 디바운스 저장, 헤더에 "✓ 저장됨" 표시.
- **세그먼트 전환**: 기록 탭 내 [일지/회고/가계부] 전환은 탭 이동이 아니라 같은 화면의 뷰 스위치.
- **바텀시트**: 오버레이 dim + 하단 슬라이드업. 유형=매수/매도일 때만 계좌 선택 노출(조건부 렌더).
- **날짜 내비게이션**: 기록·달력 간 선택 날짜 동기화(달력에서 날짜 탭 → 기록 탭 해당 날짜).
- **투자 계산식**: 대기 = max(0, 배정 − 매수). 손익은 매도 시 반영. 월 1일 배정/대기/손익 초기화.
- **반응형**: 모바일 우선(단일 컬럼, 하단 탭바). 웹에서는 중앙 정렬 컬럼 + 넓은 화면에서 달력/회고는 2컬럼 가능.

## State Management
- `authUser` (구글 로그인 사용자, uid)
- `selectedDate` (기록·달력 공유)
- `recordTabSegment`: 'log' | 'kpt' | 'ledger'
- `dailyLog`: { morning[], work[], evening[] }
- `kpt`: { keep, problem, try }
- `ledgerEntries[]`: { id, type: '지출'|'수입'|'매수'|'매도'|'적금', account?, category?, title, amount, method?, at }
- `accounts[]`: { id, name, allocated, bought } → derived: waiting = max(0, allocated-bought)
- `investPnl` (손익)
- `retroRange`: 'week' | 'month' + 기간 커서
- 파생 합계: 생활비, 기간별 수입/지출/매수/적금 합계
- 데이터 격리: `logs/{uid}` 하위에 사용자별 저장(예: Firestore). 사용자 간 비공개.

## Design Tokens
와이어프레임에서 쓰인 값 — **의미색은 유지**, 무채/포인트는 shadcn 토큰으로 매핑 권장.

의미를 가진 색 (유지):
- 수입/Keep(초록): `#2f9e69`
- 매수/Problem(빨강): `#d9694f`
- 매도/Try(파랑): `#3f7cc0`
- 지출·적금(무채): 회색 점 `#a1a1aa`, 금액은 기본 텍스트색

UI 색 (shadcn 토큰으로 대체 권장):
- 포인트/강조(인디고): `#5b5bd6` (tint `#ecebfb`, on-tint 텍스트 `#4a45c7`) → `--primary`
- 텍스트: 기본 `#2b2b2b`, 보조 `#71717a` / `#a1a1aa`
- 라인/보더: `#e4e4e7`, `#d4d4d8`
- 표면: 배경 `#ffffff`, 옅은 면 `#f4f4f5`

타이포: 와이어프레임은 Pretendard 사용. 코드베이스 기본 폰트로 대체 가능.
반경/그림자: 카드 `12px`, 버튼 `12–14px`, 시트 상단 `22px`. 그림자는 디자인 시스템 기본값 사용.
